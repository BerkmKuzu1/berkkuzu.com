VHDL problem sets

Learn VHDL by writing small circuits, from a single wire to adders, processes, generics and state machines. Each problem explains one idea; you write the architecture, press Check, and the design is simulated against a reference.

How the checker works

The checker is a VHDL-2008 simulator written in JavaScript. It parses, type-checks and simulates your code right here in your browser; nothing is uploaded. Every test vector is applied in turn and every output is compared with the reference, so wrong values, latches, missing sensitivity entries and 'U' outputs all show up.

It covers the synthesizable VHDL these problems use: std_logic and its vectors, numeric_std, processes, generics, generate, functions, enumerated types and VHDL-2008 additions such as process(all), case? and the reduction operators. Wait statements, records, procedures, files and real numbers are not supported. Every reference solution is also checked against GHDL with the same vectors.

The problem list follows HDLBits by Henry Wong, rewritten for VHDL, with extra problems on what VHDL does differently. Your code and progress stay in this browser.
